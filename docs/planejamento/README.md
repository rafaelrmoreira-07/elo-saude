# Planejamento do time

Material que o time produziu antes e durante o desenvolvimento, guardado aqui como registro. O código em `src/` é a fonte de verdade sobre o que o app faz hoje.

| Arquivo | O que é |
|---|---|
| `DECISOES.md` | Decisões do time, o que a versão final tem e as anotações das reuniões tira-dúvidas com a Rivio |
| `PERSONAS.md` | As personas fictícias (Carlos, Juliana, Lúcia, Pedro) e os dados sintéticos de cada uma |
| `PROMPTS-DO-LOVABLE.md` | O plano original (app "Cerne" no Lovable), em 9 prompts. Foi substituído pela decisão de 12/11 de evoluir o código do Matteo, mas os prompts serviram de especificação das funcionalidades |
